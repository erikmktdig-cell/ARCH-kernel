# Security Policy

## Supported Versions

Security fixes are considered only for the current `0.2.x` pre-release line.
Older pre-release revisions are unsupported.

## Reporting a Vulnerability

Do not disclose a suspected vulnerability publicly before maintainers have had
an opportunity to coordinate a response.

Report vulnerabilities privately through
[GitHub Private Vulnerability Reporting][private-report]. Do not use public
issues, pull requests, or discussions for vulnerability reports.

After a private report is received, maintainers will acknowledge and assess it,
coordinate remediation when applicable, and communicate disclosure timing with
the reporter. This describes the process, not a guaranteed response deadline.

[private-report]: https://github.com/erikmktdig-cell/ARCH-kernel/security/advisories/new
